## Что включено

- Поиск по разрешённым причинным признакам, включая вероятности бота/ML,
  репутацию и срезы. Обязательной привязки к BASE или высокому p90 нет.
- До восьми условий, в том числе нижняя и верхняя граница одного признака.
  Это ограниченный поиск, а не полный перебор всех возможных сочетаний.
- Бюджет 180 000 оценок, отдельные квоты для каждой глубины, резерв 25%
  для высокой наблюдаемой точности внутри train-поиска и финального отбора.
- Четыре последовательные группы validation по матчам, затем отдельный
  holdout. Holdout не используется для выбора кандидатов. Маленькие группы
  не считаются доказательством многонедельной устойчивости.
- До восьми новых кандидатов за цикл; поиск раз в неделю; пул до 64 правил.
  Для этого редкого профиля нет минимального количества сигналов в неделю.
- Правила фиксируются до будущих матчей. Проверки на первых 50/100/200
  срабатываниях; после первых 200 новых срабатываний больше не принимается.
  Незавершённые исходы и последующие исправления продолжают учитываться.
- 90% на завершённой фиксированной выборке означает кандидат для ручного
  рассмотрения, не доказанную истинную вероятность 90% и не автоотправку.
  Более строгая статистическая готовность проверяется отдельно.
